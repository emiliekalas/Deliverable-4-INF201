Use of Generative AI

In this deliverable we have used generative AI tools, such as Claude and Grok, as support
during our work. The AI was mainly used as a tutor: to explain concepts, help us set
up our working environment, and give feedback on our code and written text.

More specifically, AI was used for:
- **Setup and tools:** Help with creating and using the virtual environment, installing
  packages, generating `requirements.txt`, using Git and GitHub, and running pytest in
  VS Code and Jupyter.
- **Understanding concepts:** Explanations of classes, special methods (such as
  comparisons and string representations), type checking, `NotImplemented`, and
  floating-point precision.
- **Code feedback:** Reviewing our implementations and suggesting improvements. For
  example, AI pointed out that comparing values using floats can give inaccurate
  results, which led us to use exact integer arithmetic (cross-multiplication) in the
  `Fraction` class.
- **Testing:** Examples of how to structure pytest tests, and feedback on the tests we
  wrote.
- **Language:** Feedback on spelling and wording in our written discussion.

We have made sure that we understand all the code we submit, and all code has been
tested with pytest. Using AI was particularly helpful for getting started and for
understanding why certain solutions work better than others, such as the limitations
of floating-point numbers. At the same time, we experienced that it is important to
check and understand the suggestions, rather than copying them directly.
